## S8 處置階梯（「全部自動套用」怎麼套）

### 分級處置

| 級別 | 處置 |
|---|---|
| ⚪ 風格（照 last-mile-review 的通用風格與專案檔；例：拜拜日曆的破折號、中英空格、農曆寫法、祂/祂們、專名統一） | 直接改 |
| 維度一・錯字與文字品質 | 直接改 |
| 🔵 SEO（維度四） | 能直接改的直接改（標題層級、摘要、錨點文字、FAQ 格式）；要補內容才能修的（缺必要位置的關鍵字、缺段落）回 S6 補寫 |
| 🟡 精確度不足 | 降語氣為「相傳／民間說法」這類較弱的說法，不展開細節 |
| 🔴 確定錯誤／🟠 邏輯矛盾 | 走下方三階梯 |

品牌名寫法（`profile.site.brand.variants_to_fix`）屬於 ⚪ 專名統一，直接改。

### 🔴🟠 三階梯

```
階梯 1　查得到可靠來源的單一正解？
   ├─ 是 → 改成正確值，來源連結寫進 log
   └─ 否 ↓
階梯 2　多說並存、各自查得到出處？
   ├─ 是 → 改寫成並列句「主流為 X，另有 Y 說」，不裁定唯一正解
   └─ 否 ↓
階梯 3　查不到定論
   → 刪掉該句／該 bullet
```

**階梯 3 永遠存在 = 永遠有安全落點 = 永遠不需要停下來問。**
這條路上沒有「自行編造答案」的分支：階梯 1 的門檻是「查得到可靠來源」，查不到就自動下墜。

### 🟠 矛盾的補充規則

矛盾＝文章 A 段與 B 段打架。處置順序：
1. 兩段中有出處的那段為準，改掉沒出處的那段
2. 兩段都無出處 → 兩段都降語氣或都刪

（例：拜拜日曆廣澤尊王 excerpt 寫「台灣唯一翹腳造型」但正文沒說唯一 → 改 excerpt）

### 審計軌跡（必產，不是選配）

`{站}/runs/{slug}/review-log.md`，每條記：

| 位置 | 原文 | 改成 | 處置類型 | 來源 |
|---|---|---|---|---|
|  |  |  | 改值／並列／降語氣／**刪除** | 階梯 1、2 必填連結 |

沒有人看過就上稿了，這份 log 是唯一的事後檢查點。
最終報告要**單獨點出「刪除」有幾條**，那是查不到東西的地方，最可能該補內容。

last-mile-review 自己的審稿紀錄照它的專案檔寫到原本的位置（兩套共用），不另外搬。
