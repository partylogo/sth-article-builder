# 關鍵字佈局策略

> 來源：拜拜日曆 `.claude/skills/draft-article/keyword-layout.md` 全文（原本從該站 `docs/guideline/article-guide.md` 第五節提取）。
> 供撰寫文章時參考關鍵字的具體放置位置。範例沿用拜拜日曆的「天赦日拜拜」，換站時規則照用、範例只當示意。

---

## 主要關鍵字 vs 次要關鍵字

| 類型 | 定義 | 數量 |
|---|---|---|
| 主要關鍵字 | 文章最核心要搶的搜尋詞 | 1 個 |
| 次要關鍵字 | 主題高度相關的延伸詞、長尾變體或子議題 | 3-5 個 |
| 語意相關詞（LSI） | 自然出現在該主題的相關詞彙，不刻意佈局 | 不限 |

---

## 主要關鍵字佈局位置

| 位置 | 是否必要 | 說明 |
|---|---|---|
| 標題（Title） | 必要 | 自然放在標題前半段 |
| H1 | 必要 | 與 Title 一致或語意相近 |
| URL | 必要 | 簡潔包含主關鍵字 |
| Meta Description | 必要 | 在自然語句中帶入 |
| 首段前 100 字 | 必要 | 開頭自然帶出 |
| 文章中段 | 建議 | 自然出現 1-2 次 |
| 結論段落 | 建議 | 收尾時自然提及 |

**頻率：** 全文出現 3-6 次為合理範圍，重點是自然融入。

---

## 次要關鍵字佈局位置

| 位置 | 用法 |
|---|---|
| H2 標題 | 每個次要關鍵字對應一個 H2 段落 |
| H3 標題 | 次要關鍵字的細分議題 |
| 該段落首句 | 在 H2/H3 下方第一句自然帶入 |
| FAQ 問題 | 用次要關鍵字造問句 |
| 圖片 alt text | 分配給不同的次要關鍵字 |

**頻率：** 每個次要關鍵字在其對應段落出現 1-2 次即可。

## 佈局範例

例：以「天赦日拜拜」為例（拜拜日曆）：

```
設定：
├── 主要關鍵字：天赦日拜拜
└── 次要關鍵字：天赦日時間、天赦日供品、天赦日禁忌、天赦日怎麼拜

布局：
├── Title：2026 天赦日拜拜完整指南：時間、供品、流程一次看 [主要]
├── Meta Description：天赦日拜拜要準備什麼？整理天赦日時間表、供品清單與禁忌... [主要+次要]
├── H1：2026 天赦日拜拜完整指南 [主要]
│
├── 首段：天赦日是民間信仰中...也是拜拜祈福的最佳時機... [主要，首100字內]
│
├── H2：2026 年天赦日時間表 [次要：天赦日時間]
├── H2：天赦日拜拜要準備什麼供品？ [次要：天赦日供品]
├── H2：天赦日怎麼拜？完整流程 [次要：天赦日怎麼拜]
├── H2：天赦日拜拜有哪些禁忌？ [次要：天赦日禁忌]
│
├── H2：常見問題
│   ├── Q：天赦日拜拜時間幾點最好？ [次要變體]
│   └── Q：天赦日供品可以吃嗎？ [次要變體]
│
└── 結論：把握天赦日拜拜的好時機... [主要]
```

## 過度優化警示

以下情況代表關鍵字使用過度，應立即調整：

| 警示訊號 | 說明 |
|---|---|
| 同一個詞連續出現 | 例如「天赦日拜拜是很重要的拜拜，拜拜時要注意拜拜流程」 |
| 讀起來不通順 | 為了塞關鍵字而犧牲語句自然度 |
| 同義詞不自然堆疊 | 「天赦日拜拜、天赦日祭拜、天赦日祈福拜拜」連續出現 |
| 每段都重複主關鍵字 | 主關鍵字不需要在每個段落都出現 |
| 首段塞超過 2 個關鍵字 | 首段應聚焦主關鍵字 |

**核心原則：拿掉所有關鍵字策略，文章讀起來依然通順自然，那佈局就是對的。**
