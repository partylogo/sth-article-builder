# 匯入現有文件（第 4、5、6 段共用）

> 來源：plan-v5 §5.4、§6、design.md §5（寫作風格指南怎麼拆：不刪任何一條）。
> 使用者已經有寫作指南、品牌規範、查核清單、編輯守則時走這條。**整份匯入，不摘要、不刪減、不改寫成精簡版。**

## 步驟

1. **收檔**：先到 `workspace.resources` 列的資料夾（與 `site.repo_path` 的 `README*`、`docs/`）找看起來像指南、規範、守則的檔，列成候選問「是這幾份嗎？」；使用者也可以直接給檔案路徑或網址（可多個）。網址照讀取來源轉接器「抓回」拿全文。讀**全文**，不要只讀開頭。
2. **切段**：以標題為單位切成段落（沒有標題的長文以空行分隔的段落群為單位）。記下每段的原始行號。
3. **分類**：每段歸到一類，判準照 plan-v5 §5.4：

   | 這段在講 | 歸到 | 例 |
   |---|---|---|
   | **怎麼說**：語氣、人稱、句子長短、口語程度、用詞、禁用詞、開頭結尾 | brand-voice.md | 「稱呼讀者用你不用您」「轉折詞用口語版」 |
   | **要守什麼**：文章結構、內容取捨、固定模板、格式、禁止事項、寫作原則 | writing-guide.md | 「先回答再補充」「拜拜流程一律用三步驟模板」 |
   | **這種說法對不對、要不要查**：要稽核的段落、來源分級、哪類論斷要查證 | audit-rule.md | 「只稽核『X 管什麼』段落」「維基只能當跳板」 |
   | **可以用程式檢查的事**：日期換算、數字驗算、格式比對 | extensions/{名稱}.md（同時在 audit-rule 留一行指向） | 「農曆日期至少兩個獨立來源一致」 |
   | **流程或設定值**：篇數門檻、封面字數、frontmatter 欄位、分類 | profile.yaml 對應欄位（原文另抄一份進 writing-guide 的「來源原文」附錄） | 「月量 ≥ 3,000 就拆兩篇」 |
   | 只跟原本那套工具有關、新流程用不到的（例：「已學習文章清單」） | 不搬，列出來給使用者確認 | |

   一段同時講兩類時，**整段各抄一份**到兩個檔，不拆句子。

4. **給使用者確認分類**：一張表列每段的標題、行號、歸到哪、理由一句話。使用者改了就照改。「不搬」的每一條都要使用者點頭。
5. **原文照抄**：每段原文整段複製到目的檔，保留原本的標記（例：`learned:`、`seed`）、例子、表格、程式碼。只做兩件事：
   - 目的檔開頭寫來源（檔案路徑、日期、哪幾段）。
   - 原文提到原本那套工具的路徑或指令（例：「見 SKILL.md Step 6」），在後面加註「（新流程：見 …）」，不刪原句。
6. **行數核對**：來源總行數 vs 目的檔裡來自來源的行數（扣掉「不搬」的）。目的少了 → 逐段找出是哪段漏了，補回來。核對結果寫進 `{站}/setup-log.md`。
7. 寫檔。目的檔已經存在時（例：之前用問卷建過），問「合併」或「取代」，預設合併（新匯入的段落接在後面，標出來源）。
