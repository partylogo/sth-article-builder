# 第 8 段：封面

## 說明卡

**這段設定什麼**：每篇文章要不要自動產一張封面圖，怎麼產。

**為什麼需要**：S11 照這裡產封面，上稿方式支援的話一起掛到草稿上。沒設定的話不產，封面要你自己做。

**要決定什麼**：
- 產不產、用什麼方式
- 底圖與產圖腳本
- 封面尺寸：要配合網站顯示封面的比例（例：網站把封面裁成 16:9 顯示，底圖就用 16:9，不然字會被裁掉）
- 主標、副標各最多幾個字

**方法**

| 方法 | 做什麼 | 你要準備 | 時間 | 會動到外部嗎 |
|---|---|---|---|---|
| A. 我已經有產圖腳本和底圖 | 用你的腳本產一張測試圖，確認參數 | 腳本路徑、底圖路徑 | 5 分鐘 | 不會 |
| B. 給參考圖，我做模板 | 你給一張做好的封面當參考，我找或做出底圖、寫壓字腳本，出幾個字型版本給你挑 | 一張參考封面；底圖原檔（沒有的話我試著重做） | 30–60 分鐘，要來回看幾版 | 不會 |
| C. 不產 | | 不用 | 0 | 不會 |

**推薦**：使用者說過有參考圖或模板時，有腳本 → A，只有圖 → B。其他情況不標。

**跳過的話**：C。

## 方法 A 的做法

1. 問腳本路徑與底圖路徑，確認兩個檔都存在。
2. 用腳本跑一張測試圖（主標「測試標題」、副標「這是一張測試圖」，輸出到 `{站}/runs/_cover-test.jpg`），用 Read 打開給使用者看。腳本參數不是 `--title --subtitle --out` 時，讀腳本的參數說明照它的參數跑，記進 profile 的 `template_overlay.notes`。
3. 量底圖尺寸，問「網站顯示封面的比例是多少？」：使用者說不知道 → 問要不要查（讀網站程式碼的封面樣式，或打開一篇文章量封面顯示的寬高）。比例對不上時照實說會被裁到哪裡，問要不要改底圖尺寸。
4. 問主標、副標各最多幾個字（從測試圖看什麼長度會壓到圖上的元素）。

## 方法 B 的做法

1. 收參考圖（使用者貼圖或給路徑），問要保留什麼、拿掉什麼（例：「不要左上角的標籤」）。
2. 底圖：
   1. 問有沒有原檔（設計稿、沒壓字的版本）；網站程式碼裡有就去找（只讀）
   2. 沒有 → 說明可以用圖片生成工具重做一張類似的（例：用 Codex），問要不要試；不試就請使用者提供
3. 照 3 的「封面尺寸」確認比例，底圖做成那個比例。
4. 量參考圖的字：字型、粗細、大小、位置、行距。出 2–3 個版本並排給使用者挑，挑完再微調（例：「字小 4px」）。
5. 寫壓字腳本到 `{站}/cover-template/make_cover.py`，參數 `--title --subtitle --out`，規則：不覆蓋既有檔、超過行數就停並回傳錯誤、不在行首放標點。
6. 用腳本產一張測試圖給使用者看，問主標、副標字數上限。

## 方法 C 的做法

`cover.type: none`。

## 寫檔

寫進 profile 的 `adapters.cover`（`type`、`template_overlay.script`、`base_image`、`title_max_chars`、`subtitle_max_chars`、`notes`）。`notes` 記下尺寸依據與容易出錯的字（例：「英文或數字後面緊接『一』會看起來像破折號」）。

`setup.parts.cover`：A、B 測試圖使用者看過 → done；C → default；跳過 → skipped。
