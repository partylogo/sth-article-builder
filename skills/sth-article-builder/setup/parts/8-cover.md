# 第 8 段：封面設定


## 要決定的點

1. 要不要產封面、用哪種
2. 模板疊字的腳本與底圖
3. 主標樣板與字數上限

## 步驟

1. **列出目前已有轉接器的方式**：模板疊字（固定底圖＋主副標，需要一支產圖腳本）、不產。另外說一句「從文章圖片衍生、固定預設圖之後會接」。
2. **偵測**：抓 3 篇現有文章的封面（`og:image`）。三張長得像同一個模板疊不同字 → 推薦模板疊字；每張都不同或沒有 → 推薦不產。偵測結果與圖片網址列在摘要。
3. **模板疊字**：
   1. 問產圖腳本路徑與底圖路徑；確認兩個檔都存在。
   2. 用腳本跑一張測試圖（主標「測試標題」、副標「這是一張測試圖」，輸出到 `{站}/runs/_cover-test.jpg`），用 Read 打開給使用者看。腳本參數不是 `--title --subtitle --out` 時，讀腳本的參數說明照它的參數跑，記進 profile 的 `template_overlay.notes`。
   3. 問主標字數上限、副標字數上限（從測試圖看什麼長度會壓到圖上的元素；預設 8、22）。
   4. 問主標樣板（例：「{主關鍵字}是什麼」）；給 2–3 個依第 2 段讀者與文章型態推的候選。
   5. 輸出目錄預設 `{站}/runs/`（每篇的封面放在自己的 runs 資料夾）。
4. **不產**：`cover.type: none`。

寫進 profile 的 `adapters.cover`。`setup.parts.cover`：模板疊字測試成功 → done；不產 → default；跳過 → skipped。
