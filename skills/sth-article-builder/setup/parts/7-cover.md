# 第 7 段：封面

## 說明卡

**這段設定什麼**：每篇文章要不要自動產一張封面圖，怎麼產。

**為什麼需要**：每篇寫完照這裡產封面，上稿方式支援的話一起掛到草稿上。沒設定的話不產，封面要你自己做。

**要決定什麼**：
- 底圖用哪一張
- 封面尺寸：要配合網站顯示封面的比例（例：網站把封面裁成 16:9 顯示，底圖就用 16:9，不然字會被裁掉）
- 字放在哪裡
- 主標、副標大約幾個字（程式依底圖上能放字的寬度算出來。寫文章時程式直接量寬度，英文、數字比較窄，實際可以放得比這個數字多）

**方法**

| 方法 | 做什麼 | 你要準備 | 時間 | 會動到外部嗎 |
|---|---|---|---|---|
| A. 提供底圖（標題用程式自動壓） | 你給一張底圖，程式找圖上空的地方壓主標、副標 | 一張沒有字的底圖 | 5 分鐘 | 不會 |
| B. 使用內建底圖（標題用程式自動壓） | 從 3 張內建底圖挑一張（深色漸層、淺色素面、左右分色），程式壓主標、副標，左下角壓站名 | 不用 | 3 分鐘 | 不會 |
| C. 跳過 | 不產封面，封面你自己做 | 不用 | 0 | 不會 |

**推薦**：使用者說過手上有底圖 → A。其他情況不標。

壓字程式是引擎內建的 `~/article-engine/adapters/cover/scripts/overlay.py`，兩個方法都用它。

## 先確認網站顯示封面的比例（A、B 都做）

問「網站顯示封面的比例是多少？」：
1. 我知道：自己填
2. 讀程式碼查（`site.repo_path` 有值時才列）：找文章頁的封面樣式（例：`aspect-ratio`、封面元件的寬高），附檔案與行號

不知道又沒有程式碼 → 用 16:9，跟使用者說「之後看到封面被裁再回來改」。

## 方法 A 的做法（提供底圖）

1. 問底圖路徑，確認檔存在、是圖片。
2. 量底圖尺寸，跟網站比例比對。對不上時照實說會被裁到哪裡，問要不要換一張。
3. 跑 `overlay.py --base {底圖} --measure`，拿到放字區域、字色、主標副標每行最多幾個字。回傳的放字區域是「沒有夠空的區域，挑最空的」時，照實說「這張圖上沒有大塊的空地，字會壓到圖案」。
4. 產兩張測試圖，輸出到 `{站}/runs/_cover-test-{短|長}.png`，用 Read 打開給使用者看：
   - 短：主標「測試標題」、副標「這是一張測試圖」
   - 長：主標、副標都用接近上限的字數，中英混排（例：「iPhone 17 換電池一次看懂」），看會不會壓到圖案、英文後面接「一」會不會像破折號
5. 問「字的位置可以嗎？」：
   1. 可以
   2. 要移：再分兩題問（選項上限 4 個）
      - 左右：靠左／靠右／置中 → `--side left|right|center`，重量
      - 上下：靠上／置中／靠下 → `--valign top|middle|bottom`
      重產兩張測試圖給使用者看。要更細的位置就用 `--box x,y,w,h`。
6. 字數：照 `--measure` 算出來的數字寫進 `title_max_chars`、`subtitle_max_chars`，跟使用者說「這是全中文時的參考值，寫文章時程式會直接量寬度，英文、數字比較窄，實際可以放更多」。使用者想讓標題短一點，可以改小。

## 方法 B 的做法（內建底圖）

1. 依網站比例挑尺寸：16:9 用 `*-16x9.png`；接近 1.91:1（社群分享圖的比例）用 `*-191x100.png`；其他比例照實說「內建底圖沒有這個比例，字可能被裁」。
2. 把 3 張內建底圖（`~/article-engine/adapters/cover/bases/` 底下的 dark、light、accent）各壓一次短測試標題、左下角壓站名（`--brand {site.brand.name}`），並排給使用者看，問選哪一張。
   - 問「左下角要壓站名嗎？」：1. 要（預設）2. 不要。
3. 照方法 A 的第 3–6 步做（量版面、長標題測試圖、位置、字數上限）。

## 方法 C 的做法（跳過）

`cover.type: none`。

## 寫檔

寫進 profile 的 `adapters.cover`：

```yaml
cover:
  type: template-overlay
  template_overlay:
    script: {overlay.py 的絕對路徑，例：/Users/{你}/article-engine/adapters/cover/scripts/overlay.py}
    base_image: {底圖絕對路徑；B 是內建底圖的路徑}
    box: [x, y, w, h]          # --measure 的結果，或使用者移過的位置
    valign: middle             # top／middle／bottom
    color: "#ffffff"
    brand: {站名}              # 只有 B 選了要壓站名才填；A 留空
    title_max_chars: {全中文時的參考值}
    subtitle_max_chars: {全中文時的參考值}
    notes: {網站比例與依據；長標題測試看到的問題}
```

`notes` 記下尺寸依據與容易出錯的字（例：「英文或數字後面緊接『一』會看起來像破折號」）。

`setup.parts.cover`：A、B 測試圖使用者看過 → done；C（跳過）→ skipped。
