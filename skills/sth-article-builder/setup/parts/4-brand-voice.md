# 第 4 段：brand voice（怎麼說）


brand voice 管**怎麼說**：語氣、人稱（你／您）、句子長短、口語程度、舉例方式、開頭和結尾，附範例段落。用在 S6 撰稿、S8 風格檢查。沒建時用語言包的預設語氣。

## 要決定的點

1. 用哪種方式建
2. 萃取或匯入的結果對不對

## 四種建法（推薦順序依偵測結果）

| 建法 | 什麼時候推薦 | 做法 |
|---|---|---|
| 匯入既有文件 | 使用者說有品牌規範或寫作指南 | 照 [import.md](import.md)，只收「怎麼說」那類 |
| 從現有文章萃取 | content-inventory 有 5 篇以上文章 | 見下方 |
| 貼範例段落 | 文章少於 5 篇，但使用者有喜歡的範例 | 使用者貼 2–3 段，照萃取的方式分析 |
| 選預設語氣 | 零篇、也沒範例 | 朋友聊天／專業顧問／編輯部三選一，各給一段 3 句的示範 |

## 從現有文章萃取

1. 從 content-inventory 挑候選：最近發布、`content_type` 為 article、屬於撞文範圍的 8 篇。
2. 照讀取來源轉接器「抓回」，比較後挑出最能代表這個站的 3 篇（理由：篇幅完整、不是轉載或公告），列給使用者確認「用這 3 篇學語氣可以嗎？」。
3. 逐項萃取，每一項都附原文例句：

   | 項目 | 看什麼 |
   |---|---|
   | 人稱 | 稱讀者「你」還是「您」、自稱什麼 |
   | 句子 | 平均句長、一段幾句 |
   | 口語程度 | 轉折詞、語助詞、口語動詞 |
   | 開頭 | 第一段怎麼起頭 |
   | 結尾 | 最後一段怎麼收、有沒有行動呼籲 |
   | 常用與不用的詞 | 反覆出現的說法；明顯避開的說法 |

4. 寫成 brand-voice.md：每項一條規則＋✅ 原文例句；看得出「避開」的寫 ❌。最後附一段「範例段落」（從原文挑一段最典型的，原文照抄，標出處網址）。
5. 給使用者看摘要（每項一行），問「有要改的嗎？」

## 寫檔

`{站}/brand-voice.md` 開頭寫：建立方式、日期、依據（文章網址或來源檔）。
`setup.parts.brand_voice`：建了 → done；選預設語氣也算 done（檔裡寫明是預設語氣）；跳過 → skipped。
