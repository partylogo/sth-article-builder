# 維度四：SEO 檢查

從文章的 frontmatter 或內容辨識主關鍵字與次要關鍵字；辨識不出來就在報告標「無法辨識關鍵字，關鍵字相關項目跳過」，不要自己猜。

專案檔的「SEO 補充或例外」優先於本清單。

## 標題與 meta

- H1 只有一個，與標題一致，含主關鍵字
- H2／H3 層級正確、沒有跳級，掃一眼就懂全文架構
- H2／H3 盡量寫成完整問句（AI 搜尋友善）
- 每個次要關鍵字至少對應一個 H2 或 H3
- meta description（摘要）存在，長度適中（中文約 60–80 字），含主關鍵字
- URL slug 簡潔、有描述性

## 主關鍵字：只檢查必要位置

主關鍵字是否出現在下列每一個位置（**不數全文次數**）：

- 標題／H1
- URL slug
- meta description
- 首段前 100 字
- 結論段

缺哪個位置就列哪個。另外檢查有沒有堆砌：同一個詞連續出現、每段硬塞、同義詞不自然堆疊、首段塞超過 2 個關鍵字。

## 次要關鍵字

- 各在其對應段落自然出現
- 有沒有分配到 FAQ 問題中

## 內容區塊

- 開頭 2–3 句直接回答文章核心問題，不用鋪陳
- 有 FAQ 段落，至少 3 題，問題貼近讀者實際問法
- 流程類內容用編號步驟
- 提供具體數字和清單，避免模糊描述
- 結尾讓讀者知道下一步該做什麼

## 連結

- 內部連結有描述性錨點文字（不是「點這裡」「看更多」）
- 連向同一頁的多個連結，錨點文字有變化
- 內部連結指向的頁真的存在（驗證方式照專案檔；沒有專案檔就實際打開網址確認）
- 專案檔有指定 pillar 規劃時：有連回所屬 pillar 頁（1–2 個，放在前 30%），有連到同 pillar 的相關文章（1–3 個）。沒指定就跳過這項
- 有 2–3 個可信的外部連結，連在正文提到的位置，不只列在文末

## 圖片

- 有 alt text
