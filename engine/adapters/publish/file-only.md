# 發佈平台：只產出檔案

> 寫不進平台時照樣能產出一篇完整的稿子。快速開始路線的預設。

## 能力宣告

| 動作 | 支援 | 說明 |
|---|---|---|
| 建草稿 | 有 | 草稿就是 `{站}/runs/{slug}/draft.md` |
| 精準修改 | 有 | 直接改 runs/ 裡的檔 |
| 傳圖、設封面 | 部分 | 只把封面圖放進 `{站}/runs/{slug}/`，不設任何平台的封面 |
| 回傳 | `{ref: 草稿檔路徑, url: null, status: "file"}` | |

## 前置檢查

無。

## 建草稿

1. 確認 `{站}/runs/{slug}/draft.md` 存在、frontmatter 齊全（S9 已檢查過）。
2. `profile.adapters.publish.file_only.output_dir` 不是 `runs` 時，另外複製一份到那個資料夾（檔名 `{slug}.md` 或站設定指定的副檔名，例：`.mdx`），**不覆蓋**同名檔，已存在就加 `-v2`。
3. 回傳 ref。

## 報告

最終報告第一行寫「✅ 草稿檔 {路徑}（只產出檔案，沒有上平台）」，提醒裡加一則：「上線後把網址貼給我，或跑 `/sth-article-builder setup 發佈平台設定` 讓我直接寫入平台」。

產出後還沒有網址：S12 在 content-inventory 新增的那列網址留空；下次開跑前檢查會用 slug 與標題自動對到網站上的文章。
