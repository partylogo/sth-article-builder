# Keyword 搜尋量工具：無

> 來源：plan-v5 §4.2「每種外部依賴都有『無』這個選項，系統照樣能跑，只是標 ⚠️」。

## 能力宣告

| 項目 | 值 |
|---|---|
| 量的型態 | 無 |
| 相關詞 | 只有 Google 自動完成與「其他人也問了」（直接讀搜尋結果頁，沒有量） |
| 其他人也問了（PAA） | 有（讀 Google 搜尋結果頁；沒有瀏覽器時用 WebSearch 的結果） |
| 地區 | 跟著搜尋參數 |
| 成本 | 0 |

## 前置檢查

無。

## 查一個詞

1. 搜主關鍵字，記下「其他人也問了」與頁尾的相關搜尋，當成次要關鍵字候選。
2. `keyword_data` 每筆 `volume` 填 null、`volume_type` 填 `無`、`source` 填 `none`。
3. S4 不依量決定篇數：一律 1 篇；次要關鍵字從 PAA 與相關搜尋挑 2–5 個最貼近主題的。
4. 報告標 ⚠️「這篇沒有搜尋量資料，篇數與次要關鍵字是依搜尋結果頁判斷」，提醒附 `/sth-article-builder setup Keyword 搜尋量工具`。
