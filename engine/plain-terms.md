# 白話對照表

報告、提醒、setup 畫面一律用右欄的說法，不用自創術語、英文 SEO 詞與編號代稱。

| 內部用語 | 對使用者說 |
|---|---|
| cannibalization／撞文 | 站上已經有一篇在搶同一個搜尋詞 |
| SERP | Google 搜尋結果頁 |
| PAA | Google 的「其他人也問了」 |
| intent／意圖 | 搜這個詞的人想知道什麼 |
| pillar／cluster | 主題總覽頁／同主題的單篇文章 |
| keyword plan | 關鍵字規劃 |
| content-inventory | 現有文章清單 |
| 涵蓋狀態：未確認 | 這份文章清單是從網站地圖讀的，可能有漏 |
| 涵蓋狀態：已確認完整 | 文章清單是從後台或原始檔拿的，是完整的 |
| gate | 要你決定的地方 |
| auto 模式／互動模式 | 全自動／每一步都問你 |
| fan-out | 幾篇同時寫 |
| frontmatter | 文章開頭的標題、網址、摘要欄位 |
| excerpt／meta description | 搜尋結果下面那段摘要 |
| slug | 網址最後那段英文 |
| abort | 停下來沒上稿 |
| 階梯 3／刪除 | 查不到可靠資料，整句刪掉了 |
| 降語氣 | 改成「相傳」「有一種說法」這類不肯定的寫法 |
| 轉接器 | 跟某個工具或平台接的那一塊 |
| schema_version 遷移 | 設定檔格式升級 |
