# 白話對照表

報告、提醒、setup 畫面、互動模式的問題，一律用右欄的說法，不用自創術語、英文 SEO 詞與編號代稱。

**流程步驟不寫代號**（S1、S4、S8……），改寫成下面的白話名稱：

| 步驟代號 | 對使用者說 |
|---|---|
| S1 | 查關鍵字量 |
| S2 | 重複內容檢查 |
| S3 | 研究搜尋意圖 |
| S4 | 決定篇數與關鍵字 |
| S5 | 列大綱 |
| S6 | 寫稿 |
| S7 | 查出處 |
| S8 | 審稿 |
| S9 | 自動檢查 |
| S10 | 上草稿 |
| S11 | 做封面 |
| S12 | 收尾 |

用詞對照：

| 內部用語 | 對使用者說 |
|---|---|
| cannibalization／撞文 | 重複內容檢查；命中時說「站上已經有一篇在搶同一個搜尋詞」 |
| SERP | Google 搜尋結果頁 |
| PAA | Google 的「其他人也問了」 |
| intent／意圖 | 搜這個詞的人想知道什麼 |
| pillar／cluster | 主題總覽頁／同主題的單篇文章 |
| keyword plan | 關鍵字規劃 |
| content-inventory | 現有文章清單 |
| 涵蓋狀態：未確認 | 這份文章清單是從網站地圖讀的，可能有漏 |
| 涵蓋狀態：已確認完整 | 文章清單是從後台或原始檔拿的，是完整的 |
| gate | 要你決定的地方 |
| 你直接告訴我 | 手動輸入 |
| 機器閘門 | 自動檢查 |
| last-mile-review | 審稿 |
| brand voice／writing guide／audit rule | 品牌語氣／寫作指南／查核規則 |
| auto 模式／互動模式 | 全自動／每一步都問你 |
| fan-out | 幾篇同時寫 |
| frontmatter | 文章開頭的標題、網址、摘要欄位 |
| excerpt／meta description | 搜尋結果下面那段摘要 |
| slug | 網址最後那段英文 |
| abort | 停下來沒上稿 |
| 階梯 3／刪除 | 查不到可靠資料，整句刪掉了 |
| 降語氣 | 改成「相傳」「有一種說法」這類不肯定的寫法 |
| 轉接器 | 跟某個工具或平台接的那一塊 |
| schema_version 遷移 | 設定檔格式升級 |
